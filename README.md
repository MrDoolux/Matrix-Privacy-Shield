# Matrix Privacy Shield

Un petit outil PowerShell qui fait tomber la **pluie Matrix** à chaque commande exécutée.

**Objectif principal** : Brouiller l’écran pour rendre plus difficile le *shoulder surfing* (les gens qui regardent par-dessus ton épaule dans les transports, open-space, café, etc.).

### Fonctionnalités
- Effet Matrix rainbow automatique après chaque commande
- Activation / Désactivation facile (`Enable-Matrix`, `Disable-Matrix`, `Toggle-Matrix`)
- Léger et personnalisable
- Fun + un peu utile

### Installation

1. Ouvre PowerShell
2. Tape : `notepad $PROFILE`
3. Colle le contenu du fichier `Matrix-Privacy-Shield.ps1`
4. Sauvegarde et redémarre PowerShell

### Utilisation

- La pluie se déclenche automatiquement à chaque commande
- `Toggle-Matrix` → pour activer/désactiver rapidement
